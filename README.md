# Hotkey Blocker

一个用于阻止指定应用注册全局快捷键的 Windows 工具。

我讨厌各种流氓软件注册全局快捷键，导致我当前使用的软件快捷键失效。更让人恼火的是，这些设置项往往隐藏得很深，甚至根本没有设置项。

## 功能

- 添加单个应用
- 添加整个文件夹
- 支持递归匹配文件夹中的应用
- 添加应用后自动启用规则
- 自动处理之后启动的目标应用
- 启用、禁用或删除规则
- 显示应用当前状态
- 支持在系统托盘中运行
- 支持开机自动启动

## 使用方法

1. 打开 Hotkey Blocker。
2. 点击添加应用，选择需要限制的 `.exe` 文件；或者点击添加文件夹，选择一个文件夹。
3. 选择完成后，规则会自动启用。
4. 如果目标应用已经运行，请重新启动它。
5. 当应用状态显示为“已阻止”后，它将无法继续注册全局快捷键。

## 注意事项

- 已经运行的应用需要重启后才能生效。
- 禁用规则后，已经处于拦截状态的应用仍需要重启。
- 某些权限较高或行为特殊的应用可能无法处理。
- 本工具只针对应用注册全局快捷键的行为。

## 常见问题

### 为什么应用仍然可以使用快捷键？

请先确认规则已启用，并重新启动目标应用。如果仍然无效，该应用可能没有使用标准的全局快捷键注册方式，或者当前权限不足。

### 为什么显示“需要重启”？

Hotkey Blocker 发现目标应用已经在运行。请关闭并重新启动该应用。

### 为什么显示“注入失败”？

请检查目标应用是否以更高权限运行，以及程序文件是否完整。
